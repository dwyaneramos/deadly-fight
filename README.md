# To play the game

Run the file 'main.py'
Go up and down to navigate through the different players and press spacebar to start the game

# Controls

## Player 1 Controls

- WASD = Movement
- E = Primary Attack
- R = Heavy Attack
- T = Misc Attack
- F = Blocking

## Player 2 Controls

- Arrows = Movement
- , = Primary Attack
- . = Heavy Attack
- / = Misc Attack
- RShift = Blocking
